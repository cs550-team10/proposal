# Improving Curl Noise - Team 10

This project is a partial implementation of the techniques described in
*Improving Curl Noise* (SIGGRAPH Asia 2025). The goal is to generate
divergence-free vector fields for computer graphics and evaluate how tracing
and reprojection affect the resulting motion.
